\section{Answer Part 8: Working Ticket Screen - View Mode and Attachments}

Owned Ticket Detail renders Ticket fields read-only and separates the
Attachment section. Active attachments can be uploaded and downloaded. Removal
requires confirmation and a 3-200 character reason, retains metadata, and
returns \texttt{410 ATTACHMENT\_REMOVED} when a removed file is requested.
Cross-Requester Ticket and Attachment access is rejected safely.
